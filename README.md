### Week 1 Task – Understanding Software and Its Requirements

**Selected Software:** Mozilla Firefox

### Objective

The objective of this task is to understand a publicly available software application and document its key features, user flow, functional requirements, and non-functional requirements from a Quality Assurance perspective.

### Software Studied

Mozilla Firefox was selected for this task because it is a widely used, publicly available, open-source web browser.

### Report Contents

The accompanying report covers:

- Software overview
- Key features
- Typical user flow
- Functional requirements
- Non-functional requirements
- QA considerations
- Requirements summary
- Conclusion
- References
